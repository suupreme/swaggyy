# swaggyy 👖
need to leave the house in a rush? swag up easily with swaggyy. made at SASEHacks 2026
## How It Works
1. **Scans clothes** - take a picture of your clothes and it will identify if it is a top or a bottom piece
2. **Analyzes color composition** - will return the RGB value of the clothing
3. **Generates multiple outfit combinations** - will view and match the RGB values and suggest outfits
4. **Gives an "outfit of the day"** - will give a recommendation based on the highest compatibility score
## Specifications
**Frontend** - Flutter / Figma
**Backend** - Python / OpenCV 
**Databases** - Firebase
